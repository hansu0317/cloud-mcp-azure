> 문서 ID: `CRM-AI-SPEC-03`<br>
> 버전: `3.0`<br>
> 상태: `Final`<br>
> 기준일: `2026-08-13`<br>
> 적용 대상: Cloud / Local 공통 React UI<br>
> 상위 문서: [`../FINAL_HANDOVER.md`](../FINAL_HANDOVER.md)<br>
> 참조: [`01_화면정의서.md`](01_화면정의서.md), [`02_화면설계서.md`](02_화면설계서.md)

> **프로필 원칙:** 사용자에게 노출되는 메뉴는 두 프로필에서 같다. 지침 초안도 공통 메뉴다. provider를 바꾸기 위한 런타임 메뉴는 없으며 `.env`와 재기동으로 선택한다.

---

## 1. 목적·범위

이 문서는 `defineview` 메뉴정의서 예시의 메뉴 계층·위치·연결 화면·노출 조건 형식을 사용해 `/` 단일 SPA의 GNB, LNB, Content, Modal action을 정의한다.

현재 React Router는 없으며 메뉴 선택이 URL을 바꾸지 않는다. 사용자·관리자·로그아웃·권한관리 메뉴는 구현돼 있지 않다.

## 2. 메뉴 분류

| 구분 | 코드 | 위치 | 역할 |
|---|---|---|---|
| Global Navigation | `GNB` | 상단 Header | 전역 프로젝트·노트북 행동 |
| Local Navigation | `LNB` | 좌측 Sidebar | 연결·스키마·프로젝트 관리 |
| Content Action | `CNT` | Notebook/Cell | 질문 셀 행동 |
| Table Modal Action | `TBL` | 테이블 선택 모달 | 범위 검색·선택·저장 |
| Instruction Modal Action | `INS` | 지침 모달 | 지침 탭·초안·행 편집·저장 |
| Hidden/Unlinked | `SYS` | 진입점 없음 | 서버 로그 컴포넌트 |

## 3. 메뉴 계층 트리

```text
CRM AI Notebook (/)
├─ GNB
│  ├─ GNB-01 제품 로고
│  ├─ GNB-02 현재 프로젝트
│  ├─ GNB-03 Run All
│  ├─ GNB-04 셀 추가
│  ├─ GNB-05 프로젝트별 지침
│  └─ GNB-06 사이드바 토글
├─ LNB
│  ├─ LNB-01 연결 정보
│  ├─ LNB-02 스키마 갱신
│  ├─ LNB-03 프로젝트 생성
│  └─ LNB-04 프로젝트 목록
│     ├─ LNB-04-01 프로젝트 전환
│     ├─ LNB-04-02 테이블 범위
│     ├─ LNB-04-03 이름 수정
│     └─ LNB-04-04 프로젝트 삭제
├─ Content
│  ├─ CNT-01 셀 실행
│  ├─ CNT-02 셀 삭제
│  ├─ CNT-03 쿼리 펼침/접힘
│  ├─ CNT-04 답변 내보내기
│  └─ CNT-05 하단 셀 추가
├─ Table Scope Modal
│  ├─ TBL-01 검색
│  ├─ TBL-02 도메인 필터
│  ├─ TBL-03 전체 선택/해제
│  ├─ TBL-04 테이블 선택
│  ├─ TBL-05 취소
│  └─ TBL-06 저장
├─ Instructions Modal
│  ├─ INS-01 초안 생성
│  ├─ INS-02 관계 탭
│  ├─ INS-03 업무 용어 탭
│  ├─ INS-04 질문 예시 탭
│  ├─ INS-05 행 추가/삭제
│  ├─ INS-06 취소
│  └─ INS-07 저장
└─ Hidden
   └─ SYS-01 서버 로그 — 컴포넌트만 존재, 사용자 메뉴 없음
```

## 4. GNB 메뉴 매트릭스

| Menu ID | 메뉴명 | Screen ID | 노출 조건 | 활성 조건 | 동작 |
|---|---|---|---|---|---|
| `GNB-01` | 제품 로고 | `UI-01` | 항상 | - | 제품명 표시, 별도 이동 없음 |
| `GNB-02` | 현재 프로젝트 | `UI-01/02` | 항상 | 프로젝트 로드 후 | 현재 이름 표시, click 시 LNB open |
| `GNB-03` | Run All | `UI-01/05` | 항상 | 활성 프로젝트·셀이 있을 때 의미 있음 | 셀 순차 실행 |
| `GNB-04` | 셀 추가 | `UI-01/05` | 항상 | 활성 프로젝트 | 빈 AI 셀 추가 |
| `GNB-05` | 지침 | `UI-04` | 항상 | 활성 프로젝트 | 프로젝트별 지침 modal open |
| `GNB-06` | Sidebar toggle | `UI-02` | 항상 | 항상 | LNB 접기·펼치기 |

## 5. LNB 메뉴 매트릭스

| Menu ID | 메뉴명 | API | 확인/위험 | 결과 |
|---|---|---|---|---|
| `LNB-01` | 연결 정보 | 없음 | 표시점은 실시간 상태 아님 | `VITE_CONN_NAME` 표시 |
| `LNB-02` | 스키마 갱신 | `POST /api/schemas/refresh` | 중복 실행 메시지; 기존 카탈로그만 갱신 | 성공 테이블 수 표시 |
| `LNB-03` | 프로젝트 생성 | `POST /api/projects` | 이름 입력 | 새 프로젝트 활성화, 테이블 modal open |
| `LNB-04-01` | 프로젝트 전환 | `GET /api/projects/{project_id}` | 없음 | 상세·지침·셀 복원 |
| `LNB-04-02` | 테이블 범위 | `GET /api/tables`, 프로젝트 PATCH | 테이블 범위는 RBAC 아님 | `UI-03` open |
| `LNB-04-03` | 이름 수정 | 프로젝트 PATCH | 빈 입력은 기존 이름 유지 | 목록·header 이름 갱신 |
| `LNB-04-04` | 프로젝트 삭제 | 프로젝트 DELETE | 확인 필수, 복구 없음 | 파일·셀·지침·history 삭제 |

## 6. Content 메뉴 매트릭스

| Menu ID | 메뉴명 | 위치 | 단축키 | 비활성 조건 | 결과 |
|---|---|---|---|---|---|
| `CNT-01` | 셀 실행 | 셀 header | Shift+Enter | 실행 중 또는 질문 공백 | `/api/chat` SSE 처리 |
| `CNT-02` | 셀 삭제 | 셀 header | 없음 | 없음 | 빈 셀 즉시, 내용 셀 확인 후 삭제 |
| `CNT-03` | 쿼리 보기 | 셀 output | 없음 | query 없음 | 실행 도구·입력 panel toggle |
| `CNT-04` | 내보내기 | 셀 header | 없음 | `rawContent` 없음 | table이면 CSV, 아니면 TXT |
| `CNT-05` | 셀 추가 | notebook 하단 | 없음 | 활성 프로젝트 없음 | 빈 셀 추가 |

질문 셀의 도구 이벤트는 사용자가 직접 실행하는 CRM 메뉴가 아니다. 모델이 제안한 호출을 공통 FastAPI 서버가 검증·실행하고 UI에는 상태와 입력을 표시한다.

## 7. 테이블 선택 메뉴 매트릭스

| Menu ID | 메뉴명 | 입력 | 상태 변화 | 서버 변경 |
|---|---|---|---|---|
| `TBL-01` | 검색 | 논리명·표시명 | 보이는 행 필터 | 없음 |
| `TBL-02` | 도메인 | domain | 보이는 행 필터 | 없음 |
| `TBL-03` | 전체 선택/해제 | click | selected 일괄 변경 | 저장 전 없음 |
| `TBL-04` | 테이블 행 | checkbox/click | selected 추가·제거 | 저장 전 없음 |
| `TBL-05` | 취소/닫기 | click | 임시 상태 폐기 | 없음 |

## 8. 지침 메뉴 매트릭스

| Menu ID | 메뉴명 | API/데이터 | 노출 | 결과 |
|---|---|---|---|---|
| `INS-01` | 초안 생성 | `GET /api/instructions/draft` | Cloud/Local 모두 | 로그 기반 terms/examples 후보를 local form에 병합 |
| `INS-02` | 관계 | `instructions.joins` | 공통 | 관계 행 편집 |
| `INS-03` | 업무 용어 | `instructions.terms` | 공통 | 용어 행 편집 |
| `INS-04` | 질문 예시 | `instructions.examples` | 공통 | few-shot 행 편집 |
| `INS-05` | 행 추가/삭제 | local form | 공통 | 저장 전 임시 변경 |
| `INS-06` | 취소/닫기 | 없음 | 공통 | 편집·초안 폐기 |
| `INS-07` | 저장 | 프로젝트 PATCH | 공통 | 현재 프로젝트 instructions 갱신 |

초안 생성은 승인 메뉴가 아니라 편집 보조 메뉴다. 후보에 빈 테이블·컬럼·정의가 있을 수 있으므로 저장 전에 사람이 확인해야 한다.

| 출발 | 메뉴 | 도착/표시 | URL 변경 | 데이터 동작 |
|---|---|---|:---:|---|
| `UI-01` | `GNB-02/06` | `UI-02` open/collapse | X | 없음 |
| `UI-02` | `LNB-03` | `UI-03` | X | 프로젝트 생성 후 modal |
| `UI-02` | `LNB-04-01` | `UI-01` 내용 교체 | X | 상세 GET |

## 10. 노출·비활성 규칙

| 조건 | 메뉴 상태 | 근거 |
|---|---|---|
| 프로젝트 로딩 | 프로젝트 관련 행동은 로드 완료까지 제한 | 잘못된 ID 요청 방지 |
| 셀 질문 공백 | 실행해도 API 호출 없음 | `runCell` guard |
| 셀 실행 중 | 같은 셀 실행 버튼 disabled | 중복 스트림 방지 |
| 스키마 갱신 중 | 갱신 상태 표시, 서버도 중복 요청 메시지 | 중복 metadata 부하 방지 |
| 지침 초안 로딩 | 초안 버튼 disabled·진행 문구 | 중복 후보 요청 방지 |
| 내보낼 원문 없음 | export 버튼 미노출 | 빈 파일 방지 |
| 로그 기능 | 메뉴 미노출 | RBAC·마스킹 미구현 |
| LLM provider 설정 오류 | 메뉴는 그대로 보임 | chat은 HTTP 503, health로 원인 확인 |

## 13. 알려진 제약

- 사용자별 메뉴 권한과 RBAC가 없다.
- 공유 `API_KEY`가 설정돼도 메뉴가 역할에 따라 숨겨지지 않으며 현 SPA는 키를 보내지 않는다.
- provider/model 변경 메뉴가 없고 운영 환경변수와 재기동이 필요하다.
- 서버 로그·health를 위한 운영자 전용 메뉴가 없다.
- 메뉴 검색·즐겨찾기·breadcrumb·deep link·브라우저 history 복원이 없다.
- 위험 행동의 승인 워크플로는 브라우저 confirm 수준이다.
