## 0. 시작 전 확인

## 1. 🔗 테이블 연결 (조인)

**동작**: Dataverse에 실제로 있는 FK(스키마의 lookups)만 후보로 계산해서 보여준다. 사람이 직접 관계를 정의하는 게 아니라 "찾은 것 중에 고르기"만 한다.

- [ ] "테이블에서 찾아 추가하기"를 펼치면, 지금 프로젝트에 선택된 테이블들 사이의 실제 FK만 후보로 뜨는지 확인 (테이블 스코프 밖 관계는 안 보여야 정상)
- [ ] 후보 하나를 클릭해서 추가 → "등록된 연결" 목록에 바로 뜨는지, 같은 후보가 목록에서 사라지는지 확인
- [ ] 자기참조 연결(예: 거래처의 "상위 거래처")이 있다면 `테이블A → 테이블A (컬럼명 기준)`처럼 어느 컬럼 기준인지 표시되는지 확인
- [ ] ✎ 아이콘으로 설명(label) 추가 → 저장 후 다시 열어도 유지되는지 확인
- [ ] × 로 하나 삭제 → 저장 → 그 관계를 다시 "테이블에서 찾아 추가하기"에서 후보로 볼 수 있는지 확인(삭제가 후보 목록도 되돌리는지)
- [ ] **효과 확인**: 두 테이블을 엮는 질문(예: "A의 B를 같이 보여줘")을 조인 등록 전/후로 각각 물어봐서 답변이 달라지는지(정확도가 올라가는지) 비교

## 2. 📖 용어 뜻 — 이번에 새로 바뀐 부분

**동작**: Dataverse에 설명이 없는 **Boolean 컬럼만** 후보로 뜬다(Picklist 등은 이미 옵션값 자체가 설명이라 제외). 클릭하면 True/False 각각 "업무에서 뭐라고 부르는지"만 입력받고, 실제 값(`true`/`false`)은 자동으로 붙는다 — "정확한 뜻"을 직접 타이핑하던 옛날 방식은 없앴다.

- [ ] "컬럼에서 찾아 추가하기"를 펼쳤을 때, "정의 필요"로 뜨는 컬럼이 전부 Boolean 타입인지 확인(Picklist·State·Status가 섞여 있으면 버그)
- [ ] 정의 필요 컬럼 하나를 클릭 → **True/False 두 칸**이 뜨는지 확인(예전처럼 "정확한 뜻" 칸이 뜨면 캐시된 옛 화면이니 새로고침)
- [ ] True만 채워서 추가 → "등록된 용어"에 `컬럼 = "입력한 값" → true` 형태로 한 줄만 뜨는지 확인
- [ ] 같은 컬럼을 다시 클릭해서 이번엔 False만 채워서 추가 → 같은 컬럼에 대해 두 번째 줄(`→ false`)이 추가로 뜨는지 확인 — **여기가 이번에 고친 핵심**: 예전엔 한쪽만 추가하면 그 컬럼이 후보 목록에서 통째로 사라져서 나머지 값을 추가할 방법이 없었다. 지금은 그 컬럼이 계속 "이미 등록된 값 있음"으로 후보에 남아있는지, 남은 값도 추가할 수 있는지 확인
- [ ] True/False를 한 번에 같이 채워서 추가 → 두 줄이 한 번에 생기는지 확인
- [ ] "이미 설명 있는 컬럼 N개 — 펼치기"를 열어서, Picklist 등 다른 타입 컬럼에 대해서는 예전 방식(업무에서 부르는 이름 + 정확한 뜻 두 칸, Picklist는 옵션 칩)이 그대로 동작하는지 확인 — 이 경로는 이번에 안 건드렸으니 회귀 여부만 체크
- [ ] **효과 확인**: 그 Boolean 컬럼이 실제로 걸리는 질문(예: "우선순위인 것만 보여줘")을 용어 등록 전/후로 물어봐서, 등록 후엔 모델이 `eq true`/`eq false`를 헷갈리지 않고 쓰는지 확인(노트북 답변 아래 쿼리 로그에서 실제 OData 경로 확인 가능)

## 3. 💬 질문 예시 — 이번에 자동가져오기 제거됨

**동작**: 예전엔 노트북에서 방금 실행한 셀을 ✓ 버튼으로 그대로 가져올 수 있었는데, "조회가 성공했다"와 "답변이 맞다"는 별개라서 그 기능을 없앴다. 이제는 항상 손으로 입력한다.

- [ ] "새 예시 추가하기"를 펼쳤을 때 ✓ 버튼(셀 가져오기)이 **더 이상 안 보이는지** 확인 — 대신 "노트북에서 먼저 물어보고, 나온 결과가 맞는지 직접 확인한 다음 아래에 그대로 옮겨 적으세요" 안내 문구만 있어야 정상
- [ ] 질문·답변을 직접 입력해서 추가 → "등록된 예시"에 Q/A로 뜨는지 확인
- [ ] **효과 확인**: 답변 형식이 매번 들쭉날쭉하던 질문을 예시 등록 전/후로 물어봐서, 등록 후 답변 형식(표 구성, 말투 등)이 예시와 비슷해지는지 확인

## 4. 저장·검증 공통

- [ ] 용어/예시를 등록만 하고 값을 다 안 채운 채(초안 상태)로 "저장" 눌렀을 때, 그 항목은 저장 안 되고 화면에 "아직 안 채운 초안 후보 N개는 저장하지 않았습니다" 안내가 뜨는지 확인
- [ ] 저장 후 페이지 새로고침 → 등록한 조인/용어/예시가 그대로 남아있는지 확인
- [ ] 서버 로그(`logs/server.cloud.log`)에서 `API-질문` 항목의 `instructions: {joins, terms, examples}` 카운트가 실제 등록 개수와 일치하는지 확인(지침이 정말 이 질문에 반영됐는지의 가장 확실한 증거)
